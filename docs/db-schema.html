四、迁移历史

#文件内容
1000001_init初始 7 表：servers / tools / call_logs / api_keys / credentials / categories / tool_embeddings
2000002_tool_controls新增 tool_changes；tools.enabled 默认改为 0（新工具先人工审再放行）
3000003_tool_boot工具管控归一：删 server 级过滤名单两列，新增 boot_enabled_tools 一次性引导名单
4000004_server_auto_enableservers 新增 auto_enable（信任上游可自动启用新工具，默认关）
5000005_key_coolingcredentials 新增 cooling_until：限流冷却跨重启持久化
6000006_drop_tpmTPM 整条下线：删 credentials.tpm_limit 与 servers.est_tokens_per_call，只留 RPM

五、设计约定

  • 时间戳：一律 epoch 毫秒 BIGINT（integer 32 位撑不过一个月），不碰 timestamp 与时区语义。
  • JSON 存 TEXT：headers/args/env/tags/capabilities/vector 均为 JSON 字符串，读写不依赖扩展。
  • 日志只记快照：call_logs / tool_changes 存当时的名字（server_key、api_key_name），改名删行不改写历史。
  • cooling 是内存态：credentials.state 只有 active/disabled；迁移 005 后仅落「冷却到点时刻」。
  • DDL 归迁移文件独占：禁用 GORM AutoMigrate（其行内注释解析缺陷会触发 DROP TABLE 式修复）。
